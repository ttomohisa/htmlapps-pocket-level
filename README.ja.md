# Pocket Level

スマートフォンを**水平器・傾斜計**として使う、インストール不要の単一HTMLアプリです。

端末のモーションセンサーだけを使い、測定値はブラウザー内で処理します。外部API・CDN・解析タグはありません。

## 主な機能

- **平面モード** — 2軸の気泡表示、X/Y角度、合成傾斜角
- **辺・垂直モード** — スマホの長辺/短辺を使った1軸水平・垂直確認
- **勾配表示** — 角度に加えて `%` を表示
- **安定度表示** — 直近のセンサー値の揺れから「安定 / やや揺れ / 動いています」を表示
- **ゼロ設定** — 現在角度を一時的な0°基準に設定
- **固定** — 読み値をその場でホールド
- **水平判定** — ±0.1° / ±0.3° / ±0.5° / ±1.0°
- **音・振動通知** — 対応端末で水平になった瞬間だけ通知
- **画面起動ロック** — 対応ブラウザーでは測定中の画面消灯を抑制
- **2秒平均** — 2秒間の読み値を平均して固定。ばらつきも表示
- **180°反転の2点校正** — 同じ面で端末を180°回して2回記録し、端末側のX/Y偏りを推定
- **日本語 / English** — 1つのHTML内で切り替え

## 競合との差別化

一般的な水平器アプリにある「気泡・角度・ゼロ設定・許容誤差・音/振動」は押さえつつ、通常画面は極力シンプルにしています。

Pocket Level では、完全に水平な基準面を用意しにくい場面向けに **180°反転の2点校正** を用意しました。1回目の読み値を `m1 = surface + deviceBias`、同じ面で180°回した2回目を `m2 ≈ -surface + deviceBias` とみなし、`(m1 + m2) / 2` から端末側の偏りを推定します。

また、センサー値の短時間の揺れを見て安定度を表示し、必要なときだけ「2秒平均」で読み値を固定できます。これらは設定内に置き、普段の水平確認を邪魔しない構成にしています。

> 注意: ケースやカメラの出っ張りで接地状態そのものが変わる場合、校正で完全には補正できません。本アプリは精度保証された施工用測定器の代替ではありません。

## 使い方

1. HTTPSで公開したページをスマホで開きます。
2. **測定を開始** をタップし、必要ならモーションセンサー権限を許可します。
3. 平らな面は **平面**、棚板の辺や垂直確認は **辺・垂直** を選びます。
4. 必要に応じて **ゼロ設定** / **固定** を使います。
5. 細かな揺れを抑えたいときは設定から **2秒平均** を使います。

## プライバシー / オフライン

- ランタイムのネットワーク通信なし (`connect-src 'none'`)
- カメラ / マイク / GPS 不使用
- 測定値はブラウザー内だけで処理
- 設定・校正値は利用可能な場合のみ LocalStorage に保存
- 外部ライブラリなし

`dist/index.html` は完全内包です。`file://` でもUIは開けますが、ブラウザーのセキュリティ仕様によりモーションセンサーが使えない場合があります。実際の測定は HTTPS（GitHub Pages / Browser Kitty 等）での利用を推奨します。

## ビルド

Windows:

```bat
build-standalone.bat
```

または:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\build-standalone.ps1
```

生成物:

- `dist/index.html`
- `dist/index.self-extract.html`
- `dist/build-manifest.json`
- `dist/dependency-manifest.json`

リポジトリ全体のチェック:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-repository.ps1
```

## 開発

編集するのは `src/index.template.html` です。`dist/` の生成物は直接編集しないでください。

### センサーが動かない場合

Pocket Level は端末のモーションセンサーを使用します。ブラウザーによっては `file://` で直接開いたHTMLからセンサー値を取得できません。Browser Kitty / GitHub Pages など **HTTPSで配信されたページ**からの利用を推奨します。

未対応ブラウザー・安全でないページ・権限拒否・センサーイベント未受信を検出した場合は、理由を測定画面に表示し、測定開始ボタンを無効化します。実際のセンサー値を1件受信するまで `0.0°` を測定値として表示しません。
