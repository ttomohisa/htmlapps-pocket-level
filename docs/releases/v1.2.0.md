# Pocket Level v1.2.0

## 主な変更 / Highlights

- スマホの測定画面を見直し、気泡・角度・安定状態を中心に表示。補助カードを非表示にし、下部操作を「ゼロ設定」「固定」「2秒平均」の3つに整理しました。
- 設定をヘッダーへ移動。水平器の気泡・目盛り・陰影は従来のデザインを維持し、短い画面や横向き画面の重なりを調整しました。
- 左上のアイコンをfaviconに統一し、日英切替でのタイトルの見え方、設定アイコン、PCのローカル処理バッジを修正しました。
- 日英の説明文を短く整理し、ヘルプの不要な閉じ方説明を削除しました。測定機能や校正機能の計算方式は変更していません。

- Reworked the phone layout to prioritize the level, angle, and stability reading. The bottom bar now has three main actions: Set zero, Hold, and 2s average; Settings moved to the header.
- Kept the original bubble/vial artwork while improving short-screen and landscape layouts.
- Matched the header icon to the favicon, stabilized bilingual title sizing, and updated the Settings icon and desktop privacy badge.
- Shortened Japanese/English descriptions and removed redundant dialog-closing instructions. Measurement and calibration algorithms are unchanged.

See [PR #11](https://github.com/ttomohisa/htmlapps-pocket-level/pull/11) for implementation details.

## Verification / 検証

The release workflow builds both HTML variants from source, runs the repository regression suite, checks the ZIP contents, verifies SHA-256 checksums, and creates the tag and GitHub Release from the same main-branch commit.

The earlier PR passed automated Japanese/English Chromium layout checks, including narrow phone and desktop widths. Physical Android/iOS motion-sensor accuracy and permission behavior have **not** been verified by those automated tests. Pocket Level is a convenience tool, not certified surveying or construction equipment.

リリース時にビルドと回帰テスト、ZIP内容、SHA-256を確認します。スマホとPCの日英表示は自動検査済みですが、実機のセンサー精度・権限挙動は未検証です。精度保証のある測量・施工機器の代わりにはなりません。
