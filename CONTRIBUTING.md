# Contributing

- Read `AGENTS.md` and `APP_SPEC.md` first.
- Edit `src/index.template.html`; do not hand-edit `dist/`.
- Keep the release single-file, local-first, bilingual, and free of runtime network dependencies.
- Preserve accessible labels, keyboard focus, mobile safe-area handling, and reduced-motion behavior.
- Run `scripts/check-repository.ps1` before submitting changes.
- Test sensor behavior on at least one real smartphone over HTTPS for changes that touch measurement logic.
